\noindent
Real-time telemetry and continuous stream analytics are central to modern distributed infrastructure, where systems routinely process millions of events per second. Extracting fundamental aggregation primitives---point frequency estimates, cardinality approximations, and heavy-hitter rankings---by maintaining exact state requires $O(N)$ linear memory in the stream length. This causes unacceptable garbage collection pauses, memory exhaustion, and Service Level Agreement (SLA) violations. Probabilistic sketches circumvent these physical bottlenecks by delivering bounded-error answers in sub-linear memory. However, conventional sketch architectures rely on static parameter provisioning fixed at deployment time. Under bursty, skewed, or non-stationary workloads, static sketches either waste memory or suffer severe estimation degradation and latency spikes.

This dissertation presents the design, mathematical formulation, and experimental evaluation of an end-to-end distributed stream analytics platform that pairs probabilistic sketching with autonomous online control and straggler-hedged query processing. The framework integrates three complementary streaming data structures: a Conservative-Update Count-Min Sketch (CU-CMS) with exponential time-decay for point frequency estimation, a HyperLogLog (HLL) estimator for distinct item tracking, and a Sliding-Window Misra--Gries algorithm for heavy-hitter detection under non-stationary traffic.

Across two development phases, the platform evolved from an initial multi-language ingestion pipeline into an intelligent distributed system:
\begin{enumerate}
    \item \textbf{Autonomous Reinforcement Learning Control Plane:} We replace rigid heuristic thresholds with an online 108-state Markov Decision Process (MDP) Tabular Q-Learning controller and a continuous-feature LinUCB contextual bandit. The Q-Learning agent continuously tracks worker latency, memory pressure, empirical estimation error (Weighted Absolute Percentage Error), and current precision templates. By incorporating a proactive approaching-SLA zone and an anti-flapping switching penalty, the agent directly selects precision templates $\{0: \text{low}, 1: \text{medium}, 2: \text{high}\}$ in a single control cycle.
    \item \textbf{Non-Stationary Concept Drift Detection:} We introduce an $O(K)$ sketch-based drift detector that computes the $L_1$ Total Variation Distance ($D_{\text{TV}}$) over consecutive Misra--Gries heavy-hitter probability distributions, autonomously triggering controller adaptation upon distributional shifts ($D_{\text{TV}} \ge 0.15$).
    \item \textbf{Zero-Data-Loss Sketch Resizing Algebra:} We formulate and prove state-preserving modular bucket folding for Count-Min Sketches ($j' = j \pmod{w_2}$) and register bit-masking for HyperLogLog, mathematically guaranteeing that post-downgrade estimates never undercount ground truth.
    \item \textbf{Partitioned Ingestion with Hedged Monoid Merges:} To scale beyond single-node ingestion bottlenecks, stream traffic is partitioned across Apache Kafka shards using CRC32 key hashing. We exploit the algebraic Monoid properties $(\mathcal{S}, \oplus, \mathbf{0})$ of probabilistic sketches (additive matrices for CMS, bounded join-semilattices for HLL, and Space-Saving candidate maps for Misra--Gries) to perform lock-free distributed scatter-gather merges in under $500\ \mu\text{s}$. To mitigate tail-latency stragglers, we implement an asynchronous hedged-request engine that dispatches duplicate speculative requests to replica workers whenever primary response times exceed the empirical $P95$ threshold ($4.5\text{ ms}$).
\end{enumerate}

Empirical evaluation across multi-regime workloads (traffic bursts, memory saturation, and concept drift) demonstrates the efficacy of the proposed architecture. The Q-Learning controller achieves the highest composite Pareto reward ($+0.5644$), reducing controller flapping by $24\%$ relative to rule-based baselines, cutting empirical frequency estimation error by $22.4\%$ ($1.913\%$ vs. $2.465\%$), and eliminating $72\%$ of SLA violations observed under static baselines. Under 5\% injected worker straggler stalls, the hedged scatter-gather engine reduces P99 tail query latency from $73.00\text{ ms}$ down to $8.49\text{ ms}$ (an $8.6\times$ reduction) with only $5.65\%$ duplicate query overhead. The full system is validated by an automated test suite of 49 offline unit tests and verified via a live telemetry dashboard backed by Redis and FastAPI.
